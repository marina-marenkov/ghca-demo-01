## 📖 Overview

Welcome to **OctoFit Tracker** - a fitness tracking application built to demonstrate the power of **GitHub Copilot Agent Mode**! This project is part of an interactive GitHub Skills exercise that teaches you how to leverage AI-powered coding assistance to accelerate your development process.

### The Story

OctoFit Tracker was created by Paul Octo, a PE teacher at Mergington High School, who wanted to help students stay active outside of gym class. With the help of GitHub Copilot Agent Mode, Paul is building an engaging fitness app that makes exercise fun through gamification, team competitions, and personalized guidance.

Read the full story in [docs/octofit_story.md](docs/octofit_story.md).

## ✨ Features

**OctoFit Tracker** includes:

- 👤 **User Authentication and Profiles** - Secure user management and personalized profiles
- 📊 **Activity Logging and Tracking** - Log and monitor various types of workouts
- 👥 **Team Creation and Management** - Form teams and collaborate on fitness goals
- 🏆 **Competitive Leaderboard** - Friendly competition to motivate students
- 💪 **Personalized Workout Suggestions** - AI-powered recommendations based on fitness levels

## 🛠️ Technology Stack

This application uses a modern web development stack:

- **Frontend**: React.js
- **Backend**: Python with Django REST Framework
- **Database**: MongoDB
- **Development Environment**: GitHub Codespaces
- **AI Assistant**: GitHub Copilot Agent Mode

## 📚 Workshop Structure

This hands-on workshop covers:

1. **Introduction**
   - Overview of OctoFit Tracker app concept
   - GitHub Copilot Chat models

2. **Setup of Prerequisites**
   - Setting up GitHub Codespaces
   - Configuring GitHub Copilot and Copilot Chat extensions

3. **Rapid Prototyping with GitHub Copilot Agent Mode**
   - Creating project structure
   - Generating boilerplate code
   - Implementing models, serializers, URLs, and views

4. **Building Core Features**
   - Activity logging API
   - Team management
   - Leaderboard functionality

5. **Frontend and Backend Development**
   - Setting up React components
   - Implementing responsive UI
   - Connecting to backend APIs
   - MongoDB data layer integration

## 🚀 Getting Started

### Prerequisites

- GitHub account with Copilot access
- GitHub Codespaces (free tier available)

### Quick Start

1. Click the button to create a Codespace:

   [![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/marina-marenkov/ghca-demo-01?quickstart=1)

2. Follow the step-by-step instructions in [Issue #1](https://github.com/marina-marenkov/ghca-demo-01/issues/1)

3. Use GitHub Copilot Agent Mode to build the application components
